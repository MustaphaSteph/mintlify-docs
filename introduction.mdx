# Welcome to CleverAct AI

CleverAct AI is a universal AI agent platform that lets you build intelligent agents trained on your data, extend them with skills and tools, connect them to any LLM provider, and deploy them anywhere — as a chat widget, full-page app, or via API.

It's not just a chatbot builder. It's the infrastructure for AI-powered automation — from customer support and sales to internal workflows, knowledge management, and custom AI applications.

## What you can build

<CardGroup cols={2}>
  <Card title="AI Agents" icon="robot">
    Create agents trained on any data source — docs, websites, files, APIs. They reason, search, use tools, and maintain memory across sessions.
  </Card>
  <Card title="Live Chat & Handoff" icon="headset">
    Real-time messaging with intelligent routing. AI handles first contact, detects escalation signals, and seamlessly hands off to human agents with full context.
  </Card>
  <Card title="Skills & Tools" icon="wand-magic-sparkles">
    Extend agents with reusable skill packs — web search, lead capture, HTTP requests, sandbox code execution, MCP tools, and custom scripts. Build once, enable on any bot.
  </Card>
  <Card title="Deploy Anywhere" icon="globe">
    Embed a chat widget on any site, launch a full-page chat app, or integrate via REST API and webhooks. Multi-channel, multi-tenant, white-label ready.
  </Card>
</CardGroup>

## Platform capabilities

<CardGroup cols={3}>
  <Card title="Multi-Model" icon="brain">
    OpenAI, Anthropic Claude, Google Gemini, DeepSeek, Mistral, and any OpenRouter model. Switch providers per bot without code changes.
  </Card>
  <Card title="Vector Search" icon="magnifying-glass">
    Semantic retrieval powered by embeddings. Train on PDFs, DOCX, CSVs, text, URLs — the platform chunks, embeds, and indexes automatically.
  </Card>
  <Card title="Streaming" icon="bolt">
    Real-time SSE streaming with token-by-token output, reasoning traces, and tool execution events. Sub-second time to first token.
  </Card>
  <Card title="Agent Memory" icon="brain-circuit">
    Persistent per-user memory across sessions. Agents remember facts, preferences, and context — no re-explanation needed.
  </Card>
  <Card title="Teams & Routing" icon="users">
    Multi-team support with skill-based, workload-based, and round-robin routing. Role-based access, agent presence, and performance tracking.
  </Card>
  <Card title="Analytics" icon="chart-mixed">
    Conversation metrics, agent performance, usage tracking, customer health scoring, and real-time monitoring dashboards.
  </Card>
  <Card title="Webhooks" icon="webhook">
    Event-driven notifications for conversations, handoffs, leads, training, and tool executions. Build integrations with any system.
  </Card>
  <Card title="API-First" icon="code">
    Full REST API with scoped API keys, rate limiting, and auto-generated OpenAPI docs. Everything in the dashboard is available via API.
  </Card>
  <Card title="Session Variables" icon="sliders">
    Pass user context (email, plan, tenant ID) into agent sessions. Variables flow into skills, credentials, and system prompts automatically.
  </Card>
</CardGroup>

## How it works

```
Your App / Website
    ↓
Chat Widget / Full-Page App / REST API
    ↓
CleverAct AI Platform
    ├── AI Agent Runtime (PydanticAI)
    │   ├── LLM Provider (OpenAI / Claude / Gemini / ...)
    │   ├── Vector Search (semantic retrieval)
    │   ├── Skills & Tools (web search, scripts, MCP)
    │   └── Agent Memory (persistent per-user)
    ├── Live Chat & Handoff Engine
    │   ├── Smart Routing (skill / workload / round-robin)
    │   └── Real-time WebSocket Messaging
    ├── Training Pipeline
    │   ├── PDF, DOCX, CSV, Text, URLs
    │   └── Auto-chunking & Embedding
    └── Analytics & Monitoring
        ├── Conversation Metrics
        ├── Agent Performance
        └── Usage & Billing
```
