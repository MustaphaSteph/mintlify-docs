---
title: List Data Sources
api: GET /v1/chatbots/{chatbot_id}/data-sources
description: List all training data sources for a chatbot with optional filtering and sorting
---

Requires `training:read` scope.

<ParamField path="chatbot_id" type="string" required>
  The chatbot ID.
</ParamField>

<ParamField query="cursor" type="string">
  Pagination cursor from a previous response.
</ParamField>

<ParamField query="limit" type="integer" default="20">
  Number of results per page (1–100).
</ParamField>

<ParamField query="status" type="string">
  Filter by `custom_metadata.status` value (e.g. `active`, `superseded`).
</ParamField>

<ParamField query="filename_contains" type="string">
  Substring match on filename (case-insensitive).
</ParamField>

<ParamField query="tag" type="string">
  Filter where `custom_metadata.tags` array contains this value.
</ParamField>

<ParamField query="since" type="string">
  ISO 8601 date — only sources uploaded on or after this date.
</ParamField>

<ParamField query="until" type="string">
  ISO 8601 date — only sources uploaded on or before this date.
</ParamField>

<ParamField query="sort" type="string" default="upload_date:desc">
  Sort order: `upload_date:asc` or `upload_date:desc`.
</ParamField>

<RequestExample>
```bash cURL
curl https://api.cleveract.ai/v1/chatbots/bot_abc123/data-sources \
  -H "X-API-Key: ak_live_YOUR_KEY"
```

```bash cURL (with filters)
curl "https://api.cleveract.ai/v1/chatbots/bot_abc123/data-sources?status=active&filename_contains=faq&sort=upload_date:asc" \
  -H "X-API-Key: ak_live_YOUR_KEY"
```
</RequestExample>
