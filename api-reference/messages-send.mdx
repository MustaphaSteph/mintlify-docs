---
title: Send Message
api: POST /v1/messages
description: Send a message and receive a non-streaming AI response
---

## Request

<ParamField body="session_id" type="string" required>
  The session ID from [Start Session](/api-reference/sessions-create).
</ParamField>

<ParamField body="message" type="string" required>
  The user's message text.
</ParamField>

<ParamField header="Idempotency-Key" type="string">
  Optional unique key to prevent duplicate messages. If the same key is used again with different request data, returns `409`.
</ParamField>

<Note>
  **Variables are session-level.** Variables set in `customer_metadata.variables` when [creating the session](/api-reference/sessions-create) persist for all messages in that session. You do not need to re-send variables with each message.
</Note>

<RequestExample>
```bash cURL
curl -X POST https://api.cleveract.ai/v1/messages \
  -H "Content-Type: application/json" \
  -d '{
    "session_id": "ses_1234567890",
    "message": "What are your pricing plans?"
  }'
```

```python Python
import requests

response = requests.post(
    "https://api.cleveract.ai/v1/messages",
    json={
        "session_id": "ses_1234567890",
        "message": "What are your pricing plans?"
    }
)
print(response.json())
```

```javascript JavaScript
const response = await fetch("https://api.cleveract.ai/v1/messages", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    session_id: "ses_1234567890",
    message: "What are your pricing plans?",
  }),
});
const data = await response.json();
```
</RequestExample>
