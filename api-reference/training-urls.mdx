---
title: Train from URLs
api: POST /v1/chatbots/{chatbot_id}/training/urls
description: Scrape and train from web pages
---

Requires `training:write` scope. Rate limit: 10/minute. Returns `202 Accepted` — processing is asynchronous.

**Deduplication:** URLs are automatically deduplicated by SHA-256 hash of the URL string. If the same URL was already uploaded to the same chatbot and is pending, processing, or completed, it is skipped. If all URLs are duplicates, the request returns `200` with `"status": "duplicate"`.

<ParamField path="chatbot_id" type="string" required>
  The chatbot ID.
</ParamField>

<ParamField body="urls" type="string[]" required>
  List of URLs to scrape and train on.
</ParamField>

<ParamField body="mode" type="string" default="individual">
  `individual` to scrape each URL, or `sublinks` to also follow links on the page.
</ParamField>

<ParamField body="chunking_strategy" type="string" default="auto">
  How to split content: `auto`, `individual`, or `semantic_groups`.
</ParamField>

<ParamField body="custom_metadata" type="object">
  Optional metadata tags attached to every chunk created from these URLs. Used for filtering at query time.

  If your chatbot has variables with `auto_filter` enabled, include the variable values here so data is tagged for per-user isolation:

  ```json
  { "user_id": "alice" }
  ```

  See [Multi-User Isolation](/guides/multi-user-isolation) for details.
</ParamField>

<RequestExample>
```bash cURL
curl -X POST https://api.cleveract.ai/v1/chatbots/bot_abc123/training/urls \
  -H "X-API-Key: ak_live_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "urls": [
      "https://acme.com/docs/getting-started",
      "https://acme.com/docs/api-reference"
    ],
    "mode": "individual"
  }'
```

```bash cURL (with metadata for per-user isolation)
curl -X POST https://api.cleveract.ai/v1/chatbots/bot_abc123/training/urls \
  -H "X-API-Key: ak_live_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "urls": ["https://acme.com/alice/docs"],
    "custom_metadata": { "user_id": "alice" }
  }'
```
</RequestExample>

<ResponseExample>
```json 202 Accepted
{
  "session_id": "url_a1b2c3d4e5f6",
  "chatbot_id": "bot_abc123",
  "status": "processing",
  "message": "Training started: 2 URL(s)"
}
```

```json 200 Duplicate
{
  "status": "duplicate",
  "duplicate": true,
  "data_source_ids": ["ds_abc123"],
  "chatbot_id": "bot_abc123"
}
```
</ResponseExample>
