---
title: Train from Text
api: POST /v1/chatbots/{chatbot_id}/training/text
description: Add text content to the chatbot's knowledge base
---

Requires `training:write` scope. Rate limit: 10/minute. Returns `202 Accepted` — processing is asynchronous.

**Deduplication:** Content is automatically deduplicated by SHA-256 hash. If identical text was already uploaded to the same chatbot and is pending, processing, or completed, the request returns `200` with `"status": "duplicate"` instead of `202`.

<ParamField path="chatbot_id" type="string" required>
  The chatbot ID.
</ParamField>

<ParamField body="title" type="string" required>
  A name for this training data entry.
</ParamField>

<ParamField body="content" type="string" required>
  The text content to train on.
</ParamField>

<ParamField body="chunking_strategy" type="string" default="auto">
  How to split content: `auto`, `individual`, or `semantic_groups`.
</ParamField>

<ParamField body="custom_metadata" type="object">
  Optional metadata tags attached to every chunk created from this content. Used for filtering at query time.

  If your chatbot has variables with `auto_filter` enabled, include the variable values here so data is tagged for per-user isolation:

  ```json
  { "user_id": "alice", "category": "onboarding" }
  ```

  See [Multi-User Isolation](/guides/multi-user-isolation) for details.
</ParamField>

<RequestExample>
```bash cURL
curl -X POST https://api.cleveract.ai/v1/chatbots/bot_abc123/training/text \
  -H "X-API-Key: ak_live_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "title": "Pricing FAQ",
    "content": "Q: How much does it cost?\nA: Plans start at $29/month.\n\nQ: Is there a free trial?\nA: Yes, 14 days with full access.",
    "chunking_strategy": "individual"
  }'
```

```bash cURL (with metadata for per-user isolation)
curl -X POST https://api.cleveract.ai/v1/chatbots/bot_abc123/training/text \
  -H "X-API-Key: ak_live_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "title": "Alice Knowledge Base",
    "content": "Alice specific content here...",
    "custom_metadata": { "user_id": "alice" }
  }'
```
</RequestExample>

<ResponseExample>
```json 202 Accepted
{
  "session_id": "text_a1b2c3d4e5f6",
  "chatbot_id": "bot_abc123",
  "status": "processing",
  "data_source_ids": ["ds_abc123"],
  "message": "Training started: 1 item(s)"
}
```

```json 200 Duplicate
{
  "status": "duplicate",
  "duplicate": true,
  "data_source_ids": ["ds_abc123"],
  "chatbot_id": "bot_abc123"
}
```
</ResponseExample>
