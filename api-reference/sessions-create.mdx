title: Start Session

## Request

<ParamField body="chatbot_id" type="string" required>
  The chatbot ID to start a session with.
</ParamField>

<ParamField body="visitor_id" type="string">
  Optional persistent visitor ID for session continuity. If a variable with `identity: true` is configured and no `visitor_id` is provided, the variable value is used automatically.
</ParamField>

<ParamField body="visitor_name" type="string">
  Optional visitor display name.
</ParamField>

<ParamField body="visitor_email" type="string">
  Optional visitor email for identification.
</ParamField>

<ParamField body="page_url" type="string">
  The URL of the page where the chat was started.
</ParamField>

<ParamField body="customer_metadata" type="object">
  Custom metadata to attach to the session. Use the `variables` key to pass chatbot variables configured in the dashboard (Advanced tab).

  ```json
  {
    "variables": {
      "user_id": "alice",
      "plan": "premium"
    }
  }
  ```

  Variables control personalization, data isolation, and prompt injection:
  - **Required** variables must be present or the request returns `400`
  - **Auto Filter** variables automatically filter knowledge base search results
  - **Identity** variables are used as the visitor identity for analytics

  See [Multi-User Isolation](/guides/multi-user-isolation) for a full walkthrough.
</ParamField>

<ParamField body="identity_signature" type="string">
  HMAC-SHA256 signature for verified visitor identity. See [Visitor Identity](/guides/visitor-identity).
</ParamField>

## Response

<ResponseField name="session_id" type="string">
  The unique session identifier.
</ResponseField>

<ResponseField name="conversation_id" type="string">
  The conversation ID for this session.
</ResponseField>

<ResponseField name="chatbot_id" type="string">
  The chatbot ID.
</ResponseField>

<ResponseField name="greeting" type="string">
  The chatbot's greeting message.
</ResponseField>

## Session variables

If your chatbot has variables configured (dashboard **Advanced** tab or via `chatbot.settings.variables`), pass them in `customer_metadata.variables` when creating a session.

<Note>
  **Variables are sticky for the session.** Once set at session creation, variables persist for every message in that session. You do not need to re-send variables with each [Send Message](/api-reference/messages-send) or [Stream Response](/api-reference/messages-stream) call.
</Note>

### Variable flags

| Flag | Effect |
|------|--------|
| `required` | Session creation fails with `400` if this variable is missing |
| `auto_filter` | Knowledge base search is automatically filtered by this variable's value |
| `auto_train` | Training data is automatically tagged with this variable's value |
| `identity` | Variable value is used as visitor identity for analytics and session continuity |

### Variables in skills

Session variables are automatically available to any [skills](/guides/skills) enabled on the chatbot:

- **Sandbox scripts** receive variables as `VAR_` prefixed environment variables (e.g. `user_id` becomes `VAR_USER_ID`)
- **Skill credentials** can reference variables using `{{variables.X}}` templates (e.g. set a credential value to `{{variables.api_key}}` and pass the actual key per-session)
- **Decrypted credentials** are available to scripts as `CRED_` prefixed env vars (e.g. `CRED_API_KEY`)

### Example: per-user data isolation

```bash
# Configure user_id as a required, auto-filtered variable
curl -X PUT https://api.cleveract.ai/v1/chatbots/bot_abc123 \
  -H "X-API-Key: ak_live_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "settings": {
      "variables": {
        "user_id": {
          "required": true,
          "auto_filter": true,
          "auto_train": true,
          "identity": true
        }
      }
    }
  }'

# Start a session passing the variable
curl -X POST https://api.cleveract.ai/v1/sessions \
  -H "Content-Type: application/json" \
  -d '{
    "chatbot_id": "bot_abc123",
    "customer_metadata": {
      "variables": { "user_id": "alice" }
    }
  }'
```

Alice's session will only retrieve knowledge base chunks tagged with `user_id: "alice"`.
